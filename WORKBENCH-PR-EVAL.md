# Maintainer Workbench PR Evaluation

This checklist is for controlled evaluation in this fork.

1. Start processing from the item details.
2. Review the system-generated processing plan.
3. Confirm the scope before starting the review.
4. Inspect verification evidence for the current version.
5. Complete the final review before deciding how to deliver.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for contribution guidelines.
